## 🧑‍💻 About Me

I'm a full stack developer who builds production web apps end to end — from database schema and API design through to the interface people actually click on. Most of my work lives in **React, Next.js, TypeScript, Node and Django**, backed by **PostgreSQL** and **MongoDB**.

- 🏢 &nbsp;Full Stack Developer at **Ultraconic Technologies**
- 🔭 &nbsp;Currently building **Paygate**, a UPI payment gateway, and **[Ama-Mana](https://amamana.in)**, a mental health platform now live
- 🧩 &nbsp;I like the messy parts: payments, auth, role-based access, and dashboards that hold real data
- 💬 &nbsp;Ask me about **React architecture, REST/GraphQL API design, or shipping a product solo**
